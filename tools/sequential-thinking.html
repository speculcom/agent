Sequential Thinking MCP Server

Model Context Protocol
推理 本地 只读 verified lifecycle: active 核验 2026-09-29

提供单个 sequential_thinking 工具，让 Agent 以可修订、可分支的方式逐步推进复杂问题——它不产生智能，只产生结构。

适合与不适合

让 Agent 用结构化、可修订、可分支的方式推进复杂问题分析： 分解复杂问题、可能需要修正的分析、初期范围不明确的任务。

不适合简单任务——它不提升模型能力，只约束输出结构， 增加调用轮次而无收益。

固定坐标系

11 个维度，与同赛道其他对象逐项可比。

模型与开放条件
本身不调用模型，是被客户端调用的接口实现。 本 server 不产生智能，只提供结构—— 它约束的是 Agent 调用它的方式（逐步思考并允许修订）， 真正的推理仍由客户端背后的模型完成。
运行位置
本地 Node.js 进程，通过 stdio 通信。无文件与网络访问需求。
本地文件
无任何文件访问能力。不提供读写工具，是本赛道权限最窄的一类。
关机后的任务
不支持。纯计算型工具，无状态，无需后台。
工具与扩展
仅 1 个工具 sequential_thinking， 参数包含 thought、thoughtNumber、totalThoughts、nextThoughtNeeded， 以及修订（isRevision / revisesThought）与 分支（branchFromThought / branchId）控制。 输出为结构化对象。
上下文与记忆
无跨会话记忆。每次调用接收完整的思考文本， 修订与分支通过参数显式传递，不依赖服务端存储。
权限与限制
无任何权限风险：不访问文件、不访问网络、不写任何状态。 全部权限就是「能调用一个纯函数」。
适合什么任务
让 Agent 用结构化、可修订、可分支的方式推进复杂问题的分析。 不适合简单任务（增加调用轮次无收益）。
传输方式
仅 stdio。是否支持 Streamable HTTP，仓库未声明。
认证机制
无独立认证层，但这是本赛道唯一无实质权限边界的 server—— 无文件、无网络、无状态，认证与否不影响安全。
权限范围
无文件与网络访问，不读不写任何外部资源。 权限范围为空，是 MCP 赛道上权限风险最低的一类。 可放心在敏感环境使用。

头号误解

  • 以为它能让模型变聪明，实际只约束输出结构，推理能力来自模型本身
  • 以为会记住之前的思考，实际每次调用要自己带上完整上下文
  • 以为工具越多越好，本 server 只有一个工具且是有意设计
