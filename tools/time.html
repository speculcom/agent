Time MCP ServerTime MCP Server

Model Context Protocol
本地 只读 verified lifecycle: active 核验Checked 2026-10-08

只做两件事：查当前时间、换时区。无文件无网络，是权限风险最低的一类 server。

Does two things only: report the current time and convert time zones. No files, no network — the lowest-risk category of server.

适合与不适合When to use it, when not to

场景是否适合
日程安排需要准确时间✅
跨时区协作✅
避免模型编造时间✅
做定时任务 / 调度❌ 它只查询时间，不调度

最后一条是常见误解——名字叫 time，容易以为能做定时。 实际它只回答「现在几点」和「A 时区的 X 点是 B 时区几点」。

Scenarios where an agent needs the current date and time to reason about scheduling, logs or freshness.

Not a fit for anything beyond time — it is one tool with one narrow purpose.

不支持。单次时间查询为同步操作，随客户端进程结束。

提供 2 个工具：get_current_time（按指定时区取当前时间） 与 convert_time（时区间转换）。 输出为结构化时间数据，可直接消费。

无实质权限风险：不访问文件、不访问网络、不写任何状态。 全部权限是「能查询当前时间和做时区换算」。
