适合与不适合When to use it, when not to

把公开网页内容转成 Markdown 供 Agent 读取。

不适合在能访问内网的环境中使用（官方明确警告）。 也不适合需要登录态的页面，或内容由 JS 渲染的单页应用。

Scenarios needing to pull a web page's content as Markdown for an agent to read.

Not a fit for anything where reaching local or internal network addresses matters — the official README carries an explicit security warning on exactly this point.

权限范围Permission scope
风险最高的一类：文件范围无限制（不涉及文件）， 但网络范围无法收敛—— 官方警告它可访问本地与内网 IP。 无地址白名单、无审批机制。 在生产或含内网服务的环境中使用前必须评估。

头号误解Top misconception

  • 以为它能抓需要登录的页面，它只是无状态抓取Assuming it fetches pages behind a login — it is a stateless fetch
  • 以为输出是干净的 Markdown，实际结构随目标页面变化Assuming the output is clean Markdown — the structure varies with the target page
