版本控制 本地 读写 verified lifecycle: active 核验Checked 2026-10-08

MCP 官方 reference server 里的版本控制实现，作用域限定在指定 git 仓库，但具备完整的本地写操作能力。

The version-control implementation among MCP's official reference servers, scoped to a given git repository but with full local write capability.

适合与不适合When to use it, when not to

读取仓库状态、历史与 diff，并在受控前提下执行提交与分支操作。 需要明确作用域边界（限于传入的 git 仓库）的场景。

不适合需要 push / 创建 PR / 远程仓库管理的场景—— 本 server 只做本地操作，原 github server 已归档。

工具属性说明

与 filesystem server 的对比

维度filesystemgit

写操作有（write / edit / move）有且更强（commit / reset / checkout）

执行命令不提供内部调用 git 命令行

结论：git server 的写能力更强，但因为作用域限定在 git 仓库内，风险面比 filesystem 小。
