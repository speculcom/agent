Continue
编程 开源 多模型 VSCode partial lifecycle: archived 核验Checked 2026-10-08

开源、模型完全自配的 IDE 扩展。 但它已停更：Continue 被 Cursor 收购，上游仓库转入 read-only， 官网只剩收购公告 —— 代码仍可自由使用，后续不会再有更新。

An open-source IDE extension with fully self-configured models — VS Code extension, JetBrains plugin and a cn CLI over one agent core, with models configured freely in config.yaml. The official model-provider list spans Anthropic, Azure AI Foundry, Amazon Bedrock, DeepSeek, Gemini, Mistral, Ollama (local models), OpenAI, Vertex AI, xAI and "More (30 items)".

The extension itself is free; the commercial line is a separate product. The repository README states "Apache 2.0 © 2023-2026 Continue Dev, Inc." and there is no license fee for the extension — model calls are yours to pay (BYOK, or local Ollama). The commercial line is now Continuous AI at hub.continue.dev/pricing: Starter $3 / million tokens pay-as-you-go, Team $20 / seat / month (including $10 in credits per seat), Company custom (SAML/OIDC, BYOK, SLA).

But the official status has changed. Continue was acquired by Cursor; the homepage continue.dev now serves an acquisition notice, the old Hub pricing page continue.dev/pricing returns 404, and the repository is marked read-only. The last releases are the final 2.0.0 line for the VS Code extension, CLI and JetBrains plugin.

适合与不适合When to use it, when not to

  • 需要模型自由（多 provider，含 Ollama 本地模型）而不想被单一厂商锁定的人。
  • 已在 VS Code / JetBrains 里工作、希望用开源可审计扩展的人。
  • 需要把同一 agent 用到终端与 CI（cn -p）的人。

不适合需要持续维护与长期演进的场景 —— 上游仓库已 read-only，公司被 Cursor 收购，后续只会以「代码仍可自由使用」的形态存在。 也不适合依赖官方支持与持续修复的人。

A fit for three groups:

  • People who need model freedom (many providers, including local models via Ollama) and do not want to be locked to one vendor.
  • People already working in VS Code / JetBrains who want an open-source, auditable extension.
  • People who want the same agent in the terminal and in CI (cn -p).

Not a fit for scenarios needing ongoing maintenance and long-term evolution — the upstream repository is read-only and the company was acquired by Cursor, so it persists only in a "code is still freely usable" form. Also not a fit for anyone relying on official support and continued fixes.

权限与限制Permissions & limits

默认逐工具询问，可策略化放开。

IDE 侧，官方 Agent quick-start 原文："By default, Agent mode will ask permission when it wants to use a tool"

tool policies 可把特定工具设为自动或排除。 IDE 里可点 Continue 放行，或点 Cancel 拒绝。

CLI 侧口径不同。官方 headless 页原文："tools that would normally prompt for approval (ask permission) are automatically excluded"； 要写文件必须显式 --allow Write --allow Edit（或 --allow "*"）， 另有 --readonly（Plan）、--auto、--exclude。

telemetry：仓库 README 写最终 2.0.0 版「removing anonymous telemetry」。
