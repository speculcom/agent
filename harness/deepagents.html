Deep AgentsDeep Agents

LangChain
Python 开源 MIT 通用harness 长任务 子代理 partial lifecycle: active 核验Checked 2026-09-30

Deep Agents 是 LangChain 出的通用 agent harness。

它把 filesystem、子代理、上下文管理、skills 都预置好了。

开箱即跑。

官方自述：

官方原文： "batteries-included agent harness"

它的设计目标是长任务、多步流程。凡是预置的那一层，都不改代码就能替换。

Deep Agents is a general-purpose agent harness from LangChain. It ships with filesystem, sub-agents, context management and skills already in place, so it runs out of the box. The official description is "batteries-included agent harness". It is built for long, multi-step tasks, and anything in that pre-bundled layer can be swapped without changing code. The security chapter states the agent follows a "trust the LLM" model and can do anything its tools allow; boundaries must be enforced at the tool/sandbox level, not by expecting the model to self-police. LangGraph is the graph runtime, LangChain's create_agent is a minimal harness on top of it, and Deep Agents is a more opinionated harness on top of create_agent.

适合与不适合When to use it, when not to

适合三类场景。

要一个开箱即用、默认调优好、面向长任务多步流程的通用 Agent。 不想自己拼 filesystem / 记忆 / 子代理。已经在 LangChain 生态里。

不适合三类场景。

需要细粒度权限护栏 —— 官方明说不提供。 要严格控制 agent loop 形状 —— 该用 LangGraph。 想要轻量 harness —— 该用 create_agent。

Fits: you want a general agent that works out of the box, is tuned by default, and targets long multi-step tasks. You do not want to assemble filesystem, memory and sub-agents yourself. You are already in the LangChain ecosystem.

Not a fit: needing fine-grained permission guardrails — the official docs state these are not provided, so you must build your own sandbox. Needing strict control of the agent loop shape — use a custom LangGraph graph. Wanting a lightweight harness — use LangChain create_agent.

模型与开放条件Model & openness

官方自述 model-agnostic，README 列为四条原则之一。

官方原文： "Model-agnostic — works with any LLM that supports tool calling: frontier, open-weight, or local"

FAQ 进一步说明：任何支持 tool calling 的模型都行。包括：

  • frontier API（OpenAI / Anthropic / Google）
  • provider 托管的开源权重（Baseten / Fireworks）
  • 通过 Ollama / vLLM / llama.cpp 自托管的模型

接入方式是任一 LangChain chat model。换 provider 不需要改 agent 代码。

运行位置Where it runs

它是库，不是服务 —— 进程由你自己运营。

README 明确 built on LangGraph（streaming, persistence, checkpointing）。 另可配 LangSmith 做 tracing/evaluation/deployment。

agent loop 的责任分布：

本地文件Local files

Filesystem 能力是核心卖点：read / write / edit / search。

它的后端可插拔（pluggable local, sandboxed, or remote backends）。 官方另设独立 Sandboxes 页，讲隔离执行环境与 execute 工具 （SandboxBackendProtocolV2，仅 sandbox 后端暴露 shell）。

  • persistent memory（pluggable state and store backends for cross-session recall）

工具链是 "batteries-included" 定位。 官方列出的能力：

  • Sub-agents —— 隔离子上下文的委派

MCP 支持明确：官方列「bring your own functions or any MCP server」。

human-in-the-loop：可 approve / edit / reject 工具调用，发生在执行前。

上下文与记忆Context & memory

本分区"状态 ≠ 上下文"分野的教科书案例。

  • Context management = summarize long threads and offload tool outputs to disk（卸载，不是丢）
  • Persistent memory = pluggable state and store backends，支持跨会话召回

官方描述 defaults are tuned for long-horizon, multi-step work。

两种做法并存：压缩历史 + 把大工具输出落盘 + 跨会话记忆。

权限与限制Permissions & limits

官方原文："Deep Agents follows a "trust the LLM" model. The agent can do anything its tools allow. Enforce boundaries at the tool/sandbox level, not by expecting the model to self-police."

三层定位（本分区最需要讲清的一件事）

这事最容易被搞混：Deep Agents、LangChain、LangGraph 是三层。

三层职责不同。

官方 FAQ 直接回答了一个问题：这三者有什么区别？

问的是 LangGraph 与 LangChain，官方把关系拆得很清楚。

层是什么何时用
LangGraphgraph runtime（最底层编排）agent loop 的形状不合适、你要自定义图
LangChain create_agent最小 agent harness想要更轻的 harness，不要预置中间件
Deep Agents在 create_agent 之上预置 filesystem / 子代理 / 上下文管理 / skills想要完整 harness，开箱即用

三层关系，官方原话是：

LangGraph is the graph runtime. LangChain's create_agent is a minimal agent harness on top of it. Deep Agents is a more opinionated harness on top of create_agent — same building blocks, but with filesystem, sub-agents, context management, and skills bundled in.

官方还给了选择规则（这直接就是本站的选型答案）：

Use Deep Agents when you want the full harness — planning, context management, delegation — out of the box. Use [LangChain's create_agent] when you want a lighter harness without the bundled middleware. Drop to [LangGraph] when the agent loop itself isn't the right shape and you need a custom graph.

可组合性：官方明确 any LangGraph CompiledStateGraph 都能作为 sub-agent 传给 Deep Agent。

所以不是二选一。可以用 Deep Agents 打底、LangGraph 图做子代理。

⚠ 最需要注意的一条：官方把安全责任交给你

Security 章节原文：

Deep Agents follows a "trust the LLM" model. The agent can do anything its tools allow. Enforce boundaries at the tool/sandbox level, not by expecting the model to self-police.

这不是营销话术，是风险声明。 装完之后：
