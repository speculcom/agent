适合与不适合When to use it, when not to

重视编辑器性能（Rust）、语法解析准确度（Tree-sitter）与多人协作的场景。 想在一个编辑器里混用原生 Agent 与外部 CLI Agent 的用户 —— 这是它最独特的价值。

Scenarios where editor performance (Rust), syntactic parsing accuracy (Tree-sitter) and multi-user collaboration matter. Users who want to mix the native agent with external CLI agents in one editor — this is its most distinctive value.

Not a fit for people looking for an editor whose only selling point is built-in AI — Zed positions itself as an orchestration layer for agents, not as "I ship my own model". 模型与开放条件Model & openness
官方列出 5 条模型接入路径（docs/src/ai/llm-providers.md）： 一是 Zed-Hosted Models（经 Zed 计费）； 二是 API Access（用自己的 provider 额度，含 Anthropic 兼容与 OpenAI 兼容两种）； 三是 Use an Existing Subscription（复用已付费的 ChatGPT / Claude / Copilot 等）； 四是 Use a Gateway（经 OpenRouter / Bedrock / Vercel 等网关路由）； 五是 Use a Local Model（本地运行或自托管）。 路径选择由用户决定，不是绑定的单一供应商。
